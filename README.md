# 시간의 동굴

시간의 동굴(Caverns of Time) 카드 데이터입니다.


## API 편집·경량화 지침 (2026-11-14)

- 공개 API에서 읽는 대상은 `cards.json` 현재 카드 목록, `data/<CARD_ID>.json` 카드 정보와 KST 날짜별 변경, `art/` 일반 카드, `golden/` 황금 원화·애니메이션, `frame/` 프레임/텍스처/셰이더 리소스입니다. 카드·토큰 ID 및 이미지 연결을 보존합니다.
- 공개 `cards.json`, `golden/index.json`, `release-policy.json`에는 사용하지 않는 최상위 `schema` 키를 넣지 않습니다. 플러그인 내부 DB 스키마는 별개입니다.
- `render.json`, `history.json`, `*-date.json` 등 중복 집계는 커밋·배포하지 않습니다. 생성기는 임시 검증 파일로 생성할 수 있으나 Git에 복원하지 않아야 합니다. 신규 schema/호환 래퍼를 만들지 않습니다.
- `data/`가 아직 날짜 키가 아니면 실제 한국 첫 대전 가능일 및 원본 근거를 검증하여 무손실 변환합니다. 베타는 북미 사용 시각 KST 변환, 모험은 지구 개방일, 이벤트는 실제 개시일, 토큰은 부모의 사용 가능일 기준입니다.
- 잘못된 날짜 키는 삭제·통합합니다. 날짜별 추가 기록에는 바뀐 필드만 적고 표시 개행은 `<br></br>`를 사용합니다. 검증되지 않은 최초 스펙을 현재값으로 단정하지 않고 황금/프레임 바이너리는 변형하지 않습니다.
- 실제 빌드에서 쓰는 `release-policy.json`, `tools/`, `.github/` 및 검증 자료는 참조를 먼저 확인하고 정리합니다.
